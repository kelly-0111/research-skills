# Workflow Reference

Use this workflow when structuring innovative-drug materials:

```text
输入行业资料
→ 识别公司
→ 识别药物/管线
→ 提取靶点
→ 判断技术路线
→ 识别适应症
→ 判断临床阶段
→ 整理最新进展
→ 提取后续催化剂
→ 对比竞争格局
→ 标注风险点
→ 输出结构化表格
→ 形成待确认清单
→ 定期更新
```

Recommended first pass for broad tasks:

1. Company pool from lists and reports.
2. Priority scope selection by modality or company.
3. Pipeline extraction from higher-confidence sources.
4. Catalyst extraction from research decks and announcements.
5. Verification queue for missing facts.
