# 投研助手本地工具：第一次试用步骤

## 先确认这几件事

这个文件主要是给第一次试用的人看的。  
如果只是日常使用，可以直接看 `使用说明.md`。

第一次试用时，建议先确认：

1. 这两个文件夹在同一个总文件夹里：
   - `research_assistant_app`
   - `investment_research_skills_share_package`

2. 本地已经安装 Python 3.10 或以上版本。

3. 打开 `research_assistant_app` 文件夹后，按自己的系统启动：
   - Windows：双击 `research_assistant_app/启动.bat`
   - Mac：双击 `research_assistant_app/启动.command`

4. 浏览器打开后，先用示例文件跑一遍，确认能生成报告和下载文件。

## tips

这个工具不用打开 GitHub，也不用写代码。

先安装 Python，然后双击启动脚本。网页打开后，选择要跑的功能，上传表格，点按钮，最后下载报告。

## 文件夹结构必须保持这样

```text
投研助手交付包/
  research_assistant_app/
    app.py
    启动.bat
    启动.sh
    启动.command
    使用说明.md
  investment_research_skills_share_package/
    skills/
    templates/
    examples/
```

## 第一次试运行建议

1. 先跑「卖方研究员画像」。
2. 用 `investment_research_skills_share_package/examples/analyst_profiler/sample_analyst_call_log.csv` 做测试。
3. 如果能下载 `analyst_profile_report.md` 和 `analyst_scorecard.csv`，说明本地工具基本可用。
4. 再跑「创新药分析」，确认能下载 `innovative_drug_analysis_report.md`。
5. 最后跑「股票异动监控」，因为它依赖公开行情和新闻网络接口，最容易受网络影响。

## 当前限制

- 股票异动监控需要联网。
- Excel 读取默认读取第一个 sheet。
- 创新药分析现在是公司列表到种子表和分析框架，不等于完整数据库；预测部分需要后续资料核验。
- 输出内容是投研 workflow 辅助材料，不构成投资建议。
