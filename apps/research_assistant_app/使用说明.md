# 投研助手本地工具使用说明

## 怎么用

1. 安装 Python 3.10+。
2. 解压交付包，确认 `research_assistant_app` 和 `investment_research_skills_share_package` 在同一个总文件夹内。
3. 打开 `research_assistant_app` 文件夹。
4. Windows 双击 `启动.bat`；Mac 双击 `启动.command`。
5. 浏览器会打开 `http://127.0.0.1:5199`。
6. 选择功能，上传 CSV/Excel，或在创新药分析中直接搜索公司池，点击按钮，下载报告。

## 当前支持

| 功能           | 输入                                      | 输出                                                 |
| -------------- | ----------------------------------------- | ---------------------------------------------------- |
| 股票异动监控   | 自选股 CSV/Excel                          | 日报、异动明细、原因核验表                           |
| 卖方研究员画像 | 标准 call log 或 Alpha Pai 导出 CSV/Excel | 评分卡、画像报告、行级评分表                         |
| 创新药分析     | 内置创新药公司池搜索，或 Markdown 公司列表 | Excel工作簿、分析报告、公司主表、管线种子表、催化剂表、BD交易表、待核验清单 |

## 重要说明

- 这是本地网页工具，不需要打开 GitHub 或 IDE。
- 不需要安装 Flask、pandas 或 openpyxl。
- 股票监控需要联网访问公开行情和新闻 RSS。
- 网页里的股票监控默认使用快速模式：优先保证实时行情、异动判断和报告生成，不让 K 线接口拖慢页面；如需完整 K 线连续涨跌，可用命令行脚本跑深度版。
- Excel 默认读取第一个 sheet。
- 创新药分析会生成一个 `innovative_drug_analysis.xlsx`，包含靶点全景、靶点-适应症明细、阶段分布、BD合作、催化剂追踪和待核验清单。
- 创新药分析可直接从内置公司池选择公司；报告里的预测是基于公司池和已上传资料的情景推演，需要继续用公告、临床登记、研报和行情数据核验。
- Wind 不是必需项；如果要配置自己的 Wind Key，请看 `docs/WIND_SETUP.md`。不要共用别人的 Key。
- 所有输出仅用于投研 workflow，不构成投资建议。
